Awarded for successfully completing the Totara Suite Site Administration program for v19.
## Particulars ##
**Issued:** 3rd February 2026

**Issued By:** Totara Community

**Course:** Totara Suite Site Administrator V19.

**Awarded For:** Successfully completing the Totara Suite Site Administrator V19 program.

## Criteria: ##
To receive the badge, the owner had to demonstrate their ability to use the following features at Site Administrator level in Totara version 19:
- Site Administration:
  - Reports
  - Notifications
  - Localisation
  - Dashboards and basic theming
  - Core plugins and configurable features
  - Mobile App
- User Management:
  - Creating users
  - Positions, Organisations, and Job assignments
  - Audiences
  - Multitenancy
  - Site-level user management
  - User data management
- Learning Management:
  - Catalogue
  - Courses and Categories
  - Seminar management
  - Content marketplace
  - Programs and certifications
  - Learning plans
  - Evidence
  - Badges
- Collaboration and User-Generated Content:
  - Workspaces
  - Totara Engage and Microsoft Teams
  - Playlists and resources
- Performance Management:
  - Appraisals
  - Competencies in Totara Perform
  - Goals
